# Angelina Serpes — Portfolio

A personal portfolio website showcasing my projects, work, interests, and creative explorations.

Built with Next.js and focused on smooth interactions, motion, and a clean, responsive user experience.

## Technologies

- Next.js
- React
- JavaScript
- Framer Motion
- GSAP
- Lenis
- Tailwind CSS
- Styled Components
- PostCSS
- pnpm

## Features

- Interactive landing page
- Smooth scrolling
- Scroll-based animations
- Framer Motion animations
- GSAP interactions
- Animated page transitions
- Interactive project showcase
- Responsive design
- Magnetic buttons
- Custom navigation interactions
- Custom 404 page

## Pages

- Home
- About
- Work
- Contact

## Running Locally

Clone the repository and install the dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Then open:

```text
http://localhost:3000
```
